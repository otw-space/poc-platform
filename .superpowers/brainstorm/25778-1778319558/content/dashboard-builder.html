支持的图表类型 & 维度组合

图表类型 适用维度 (X轴) 适用指标 (Y轴) 示例
柱状图区域/城市/类型/状态/PM/销售项目数量 / 平均工期各区域项目数量
条形图同上（横向）同上各PM负责项目数排行
饼图任一分类字段项目数量（占比）各状态项目占比
折线图时间（月份/季度）项目数量/完成数月度PoC趋势
组合图时间 + 分类双指标（柱+折线）项目数（柱）+ 平均工期（线）

仪表盘配置 JSON 结构

{
  "name": "华东区月度报告",
  "filters": [
    {"field": "region", "op": "eq", "value": "华东"},
    {"field": "status", "op": "in", "value": ["进行中", "已完成"]},
    {"field": "start_date", "op": "gte", "value": "2026-01-01"}
  ],
  "charts": [
    {
      "id": "chart-1",
      "type": "bar",
      "title": "各城市项目数量",
      "x_field": "city",
      "y_field": "count",
      "w": 6, "h": 4
    },
    {
      "id": "chart-2",
      "type": "pie",
      "title": "PoC类型分布",
      "x_field": "poc_type",
      "y_field": "count",
      "w": 3, "h": 4
    }
  ]
}
