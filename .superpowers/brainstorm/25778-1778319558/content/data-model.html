PoC 管理平台 — 数据模型设计

核心实体关系与字段定义

1. 项目表 (poc_projects)

字段 类型 说明
idUUID主键
nameString项目名称
regionString区域
cityString城市
salesString销售
pmString项目经理
start_dateDate开始日期
end_dateDate完成日期
duration_daysInteger工期（工作日，自动计算）
poc_typeFK → poc_optionsPoC类型
impl_methodFK → poc_options实施方式
statusFK → poc_options状态
resultTextPoC结果
created_byFK → users创建者
created_at / updated_atDateTime时间戳

2. 选项字典表 (poc_options)

统一管理所有下拉选项，支持用户自定义扩展

字段 类型 说明
idUUID主键
categoryEnumpoc_type / impl_method / status
labelString显示名称
is_defaultBoolean是否系统默认（不可删除）
sort_orderInteger排序

3. 仪表盘视图表 (dashboards)

字段 类型 说明
idUUID主键
nameString仪表盘名称
user_idFK → users所属用户
configJSON仪表盘配置（图表布局、筛选条件等）
is_publicBoolean是否公开

4. 用户表 (users)

字段 类型 说明
idUUID主键
username / password_hashString登录凭据
roleEnumadmin / user
display_nameString显示名称
